# Publishing a community release

1. Run `cargo test --locked`, `npm test` and `python3 tools/build.py`.
2. Validate and sign using the official OpenIDEA CLI:

```sh
openidea-plugin check .
openidea-plugin pack . --key /secure/path/hdpsowk-rgb.key --publisher hdpsowk-rgb --out release/hdpsowk-rgb.svn-0.1.6.oiplugin
```

3. Attach the signed `.oiplugin` to a GitHub release and compute its SHA-256.
4. Submit/update `plugins/hdpsowk-rgb.svn.toml` in `l0ng-ai/openidea-plugins` with the release URL, version and hash. The initial publisher registration also contains the public signing key.

The private signing key is kept outside this repository and must never be uploaded. Retain it for future compatible updates. The `.oiplugin` generated by `tools/build.py` is unsigned until the official `pack --key` command replaces it.
