## 更新内容

- 目录支持双击展开/收起；文件双击仍打开差异。
- 增加忽略、取消忽略及“显示已忽略”。只修改父目录的 svn:ignore，保留其他规则和本地文件；同名规则按字面文件名匹配。
- 取消本目录的通配符忽略时提供明确的规则编辑器，不自动改写继承/全局规则。
- 点击目录行执行还原时，明确确认整个目录范围；勾选文件后的还原只处理选中路径。
- 增强本地内容保护：复制/替换目录、阻塞项目、已删除但被重新创建的路径会拦截；确认后重新检查磁盘状态和忽略属性。
- 保留树状/列表切换、面板样式优化和默认关闭的自动刷新。

需要本机安装 SVN 命令行客户端。沿用原发布者签名，无新增权限或依赖。复制/替换目录需先备份后在 IDE 终端明确处理。

验证：61 项 Rust 测试、10 项 Node 测试、独立审阅修正、Wasm 构建与官方安装包检查通过；真实 SVN 覆盖规则保留、通配符名称、还原与本地内容保护。界面通过模拟宿主的浏览器预览验证。Windows GUI 和远程主机尚未实测。
